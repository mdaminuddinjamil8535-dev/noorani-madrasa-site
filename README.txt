নূরানী তা'লীমুল কুরআন মাদরাসা — ওয়েবসাইট প্যাকেজ

ফাইল:
- index.html: ওয়েবসাইটের ডিজাইন
- content.js: সহজে পরিবর্তনযোগ্য লেখা, ফোন নম্বর, বৈশিষ্ট্য ও গ্যালারি
- site.js: content.js-এর তথ্য ওয়েবসাইটে দেখায়; সাধারণত বদলাতে হবে না
- assets/: লোগো ও মাদরাসার ছবি
- EDIT-GUIDE-BN.txt: বাংলায় সম্পাদনার নির্দেশিকা

দেখতে: ZIP Extract করে index.html Chrome-এ খুলুন।
সম্পাদনা: content.js Notepad-এ খুলে EDIT-GUIDE-BN.txt অনুসরণ করুন।
প্রকাশ: ওয়েবসাইটটি এখনো অনলাইনে প্রকাশিত হয়নি। বিনামূল্যে GitHub Pages-এ প্রকাশ করা যাবে।
